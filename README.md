# Без планов

Мобильный сервис для выбора впечатлений вдвоём, самостоятельного отдыха и поездок по Москве.

**Текущая версия: 0.4 (локальный персонализированный планировщик).**
Публичный сайт: https://bez-planov.pages.dev

## Что работает

- Выбор периода 1–14 дней, режим общего путешествия или отдельных дней.
- Бюджет на день/период, количество участников, опциональные расходы на транспорт и ночёвки.
- Раздельные предпочтения двух участников: нравится / подходит / исключить; персональные тексты, повод, атмосфера и комфорт.
- Частичное распознавание простых русских фраз из свободных ответов по словарю. Противоречия и исключения учитываются в подборе.
- Выбор из редакционной базы 57 мест Москвы в 8 районах, объяснение рекомендаций и инфографика совпадений.
- Закреплённые события и время, сохранение маршрутов, отзывы «не подходит», избранное, карты Google и Яндекса, текстовое распространение.
- Локальный профиль и управление данными с браузера.
- Проверки в Playwright на WebKit с профилем iPhone и Chromium.

## Что пока НЕ работает

**Это не подключённая генеративная ИИ-модель.** Сервис не делает запросы к языковому ИИ и не понимает произвольные тексты вне заранее заданных правил. Он не проверяет актуальные цены, расписания, живые геоданные, билеты, заведения и меню. Время между остановками резервируется приблизительно, расстояния не рассчитываются. Нельзя бронировать через этот сайт, хранить профиль в облаке или синхронизировать его с другим устройством. Невозможно гарантировать доступность без ступеней и соблюдение диетических ограничений по неподтверждённым данным.

Суммы в карточках — **плановые резервы**, а не реальные цены заведений.

## Технологии

Нулевой сборочный шаг для сайта Cloudflare Pages: `index.html`, `style-v04.css`, `art-moscow.svg`, `catalog.js`, `planner-v04.js`, `ui-v04.js`. Старые файлы v0.3 сохранены ради безопасной истории и не используются страницей.

Тесты (локально):
```bash
npm install
npx playwright install --with-deps chromium webkit
npm test
```
GitHub Actions: `.github/workflows/site-check.yml`.

## Чтобы получить настоящую версию 1.0

1. Безопасный сервер (например, Cloudflare Workers), конфиденциальный ключ к ИИ или Workers AI binding, контроль затрат, лимиты запросов и согласие на передачу пользовательского текста.
2. Живые источники карточек мест, координат, часов работы, стоимости и ссылок на бронирование.
3. Настоящий расчёт маршрутов и доступности транспорта с учётом погоды, продолжительности и начальной точки.
4. Надёжные источники фотографий мест с проверенными правами и атрибуцией.
5. Аккаунты, синхронизация устройств, хранение данных по согласию, контроль приватности и удаления.
6. Реальные пользовательские проверки на iPhone, включая Safari, слабую сеть, разные размеры экрана, доступность интерфейса и многодневные сложные сценарии.

Пока интеграции не подключены, интерфейс обязан объяснять ограничения без имитации реального ИИ.
