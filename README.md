# Без планов — персональные маршруты по Москве

Публикация: https://bez-planov.pages.dev

## Версия 0.5 · Премиальный локальный планировщик

Проект создаётся для двоих (также поддерживаются один человек и небольшая компания). Он узнаёт предпочтения участников отдельно, сопоставляет общие интересы и несовпадения, принимает свободные ответы и подбирает многодневные планы из редакционного каталога.

### Реализовано

- Современный адаптивный дизайн с авторской иллюстрацией Москвы, восьмью оригинальными постерами районов и собственной системой SVG-иконок.
- Галерея вдохновения с выбором начального района.
- Даты с–по (1–14 дней), единое путешествие или самостоятельные программы на каждый день.
- Бюджет на день или весь период, компания 1–6 человек, резервы на транспорт и ночёвки (ночёвки исключительно по желанию).
- Отдельные анкеты участников, 16 тематик с оценками нравится/подойдёт/запрет, открытые ответы и частичное словарное распознавание отрицаний.
- Учет желаемых и ранее посещённых **распознанных мест**, повода встречи, эмоций, физической нагрузки, времени дня и запретов.
- Бронирования, которые пользователь уже сделал самостоятельно: фиксированное время и стоимость, защита от пересечений.
- Рекомендации из реальных названий мест, группировка по районам, объяснения причин и честная сводка списка желаний.
- Ссылки на Яндекс.Карты, Google Maps и некоторые официальные страницы заведений.
- Сохранение маршрутов, закрепление и замена остановок, избранное, исключение «не подходит», сохранение вкусов пары и старых маршрутов v0.3.
- Экспорт .ics, печатная программа на все дни, локальные заметки-воспоминания, удаление данных браузера.
- Проверки в Playwright (WebKit с профилем iPhone и Chromium), регрессионные и property-based сценарии.

### Ограничения — принципиально важно

**В этой версии нет подключённого языкового ИИ.** Алгоритм является локальным и объяснимым, с ограниченным словарём русского языка. Он не интерпретирует произвольный текст так, как большая языковая модель. Отдельные именованные места, отсутствующие в каталоге, останутся заметкой.

**Цены в маршрутах — бюджетные резервы, а не проверенные цены.** Не проверяются график работы, билеты, бронирование, фактические расстояния, пробки, прогноз погоды и требования безбарьерной доступности. Ссылки на карты помогают открыть внешнюю навигацию, но встроенная условная схема не является настоящей картой.

**Нет реального аккаунта или облачной синхронизации.** Ответы, заметки, маршруты и избранное остаются в localStorage браузера на устройстве пользователя. Встроенное меню позволяет удалить данные. Сайт не загружает персональные ответы на сервер, пока пользователь явно не подключит такую функцию в будущем.

### Почему такой порядок

Публичный продукт требует серверной части (Cloudflare Workers/Pages Functions) для настоящего ИИ с безопасно сохранённым API-ключом или Workers AI binding, гео- и событийных источников, политик хранения данных и согласия пользователей. Нельзя имитировать эти функции фальшивыми результатами или записывать ключи в статический HTML.

### Запуск тестов

```bash
npm install
npx playwright install --with-deps chromium webkit
npm test
```

GitHub Actions запускает проверки на PR и в main: `.github/workflows/site-check.yml`.

Основные файлы: `index.html`, `catalog.js`, `planner-v04.js`, `ui-v04.js`, `premium-v05.js`, `style-v04.css`, `premium-v05.css`, `assets/`.

Авторские изображения размещены внутри `assets` и не требуют внешнего сервиса изображений. Внешняя загрузка Google Fonts может использоваться только как прогрессивное оформление; есть системные шрифтовые альтернативы.
