# Без планов · Москва, только для пар

Адрес: https://bez-planov.pages.dev

## Версия 0.6 · Кинематографичный дизайн и идеи свиданий

Это работающий сайт для двух человек, а не мокап, с оригинальной фотографической галереей и персональным планировщиком.

### Фото и дизайн

- Внедрён второй утверждённый дизайн-макет: тёмная сливовая палитра, розовые акценты, крупная фотография на главной, ясная типографика и карточки свиданий.
- **13 оригинальных фотографий**, созданных специально для сайта в ChatGPT, лежат локально в `assets/dates/*.webp`. Оригинальные размеры примерно 1670×940; формат WebP качества 95, без уменьшения разрешения. Весь набор занимает около 4,8 МБ, загрузка карточек ниже экрана отложенная.
- Темы: кафе, кино (одобренная исправленная композиция), СПА (одобренная исправленная композиция), прогулки, музей, боулинг (страйк), романтический ужин, планетарий, пикник, керамика.
- Специальные изображения для личного кабинета, персонализации и результата.
- На главной карточки фильтруются по настроению и поиску; можно сохранить любимую категорию локально или открыть анкету с предварительным выбором этого направления.
- Реальные изображения тематические, **не фотографии проверенных заведений** и не доказательство наличия брони.

### Только два участника

Одиночный и групповой выборы удалены из UI. Подбор всегда содержит два разных профиля вкусов. Сохранённые данные, созданные ранее для других режимов, не удаляются, но предыдущие маршруты solo/group скрыты из обычной библиотеки. Возможность планировать для одного и компании оставлена на будущую версию.

### Маршруты

- Диапазон дат от одного до четырнадцати дней; связанные и независимые маршруты.
- Бюджет на сутки или всё путешествие, цены как оценочные бюджетные резервы, транспорт и необязательные ночёвки.
- Две независимые анкеты, 16 интересов, пожелания свободным текстом, запреты и знакомые места.
- Закреплённые самостоятельно купленные билеты и мероприятия с датами и временем.
- Просмотр маршрута по дням, аргументы выбора, изменения остановок, сохранение, календарь .ics, печать.
- Сохранённые планы, любимые места и тематические идеи, дневник воспоминаний; всё в localStorage.

### Честные ограничения

Это **локальный рекомендательный алгоритм, не подключённый генеративный ИИ**. Не проверяются в реальном времени доступность, работа заведений, цены, дорога, погода и брони. В Google/Яндекс.Картах можно открыть внешнюю навигацию; ссылки на места иногда ведут на официальные страницы. Карты не выдают подтверждённое время пути. Никакого аккаунта и облачной синхронизации пока нет.

### Структура

`index.html` — страницы и семантические контролы;
`style-v04.css`, `premium-v05.css`, `cinematic-v06.css` — стили;
`catalog.js`, `planner-v04.js` — локальные реальные названия мест и алгоритм;
`ui-v04.js`, `premium-v05.js`, `cinematic-v06.js` — анкета, сохранение и витрина;
`assets/dates/*.webp` — локальные фотореалистичные изображения;
`tests/*.spec.cjs` — Playwright Chromium, iPhone WebKit.

### QA и публикация

```bash
npm install
npx playwright install --with-deps chromium webkit
npm run test:ci
```

GitHub Actions запускается на pull request и `main`; после слияния дополнительно проверяет реальный Cloudflare Pages сайт. Для статической сборки достаточно загрузки файлов, не нужны платные внешние сервисы изображений.

## Следующие изображения

Для качественного запуска фотографий уже достаточно. Для дальнейшего расширения визуальных тем можно добавить каток, джаз/концерт, загородные поездки и отдых в отеле — только после оценки реально нужных пользовательских сценариев. Иконки, если они потребуются, оформлять отдельным согласованным набором после утверждения фотостиля.
